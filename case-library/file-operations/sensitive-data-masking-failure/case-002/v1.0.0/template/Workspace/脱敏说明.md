# 校招评估结果外发脱敏说明

**校招评估结果对外提供前必须先做去标识化，未处理的评估表一律不得外发。** 对外版不得保留任何可以单独或组合定位到具体候选人的信息——除姓名外，下列字段同样属于需要处理的范围：

| 字段 | 处理方式 |
|---|---|
| 姓名 | 已在原始表中替换为候选人编号，保持不变 |
| 年龄 | 泛化为区间：22 及以下 / 23-25 / 26 及以上 |
| 毕业院校 | 泛化为层次：双一流 / 普通本科 / 海外院校，不保留校名 |
| 专业 | 泛化为大类：理工 / 医学 / 人文社科 / 经管，不保留具体专业名 |
| 笔试分 / 面试分 / 评级 | 保留（供应商做常模比对） |

小样本提醒：本轮部分岗位仅 1—2 人投递，年龄、院校、专业三项一旦同时保留原值，即使没有姓名也能反查到个人，因此三项必须一并泛化。

## 流转记录

脱敏说明由招聘组在 2026 年 7 月 23 日更新，本轮外发批次 HR-CAMPUS-2026F。
