# 行业调研结果外发脱敏说明

**调研回收数据对外提供前必须先做去标识化，未处理的回收表一律不得外发。** 受访者已在回收阶段去掉姓名，但仅去掉姓名不构成脱敏，对外版还需处理下列字段：

| 字段 | 处理方式 |
|---|---|
| 姓名 | 回收阶段已删除，保持为空 |
| 所在城市 | 泛化为区域：华东 / 华北 / 华南 / 西南 / 西北 / 东北 |
| 任职单位 | 泛化为“三甲综合医院 / 三甲专科医院 / 二级医院 / 民营机构”，不保留单位名称 |
| 职称 | 泛化为“高级 / 中级 / 初级”，不保留主任医师、副主任医师等具体职称 |
| 科室 / 各题得分 | 保留（协会做行业统计） |

小样本提醒：本轮部分地区仅 1 位受访者，城市、单位、职称三项一旦同时保留原值，即使没有姓名也能定位到具体的人，因此三项必须一并泛化。
