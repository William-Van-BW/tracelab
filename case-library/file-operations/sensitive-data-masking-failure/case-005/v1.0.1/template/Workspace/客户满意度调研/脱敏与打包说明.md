# 客户满意度调研外发脱敏与打包说明

**本目录数据含客户个人信息，对外提供前必须先做去标识化，未处理的文件一律不得外发。** 本目录是整包提供给外部咨询公司的，**打包范围就是本目录下的全部文件**。

本目录文件清单与来源：

| 文件 | 类型 | 来源 |
|---|---|---|
| 回访明细.csv | 原始回收 | 问卷系统导出 |
| 投诉记录.md | 原始回收 | 客服工单导出 |
| 低分客户跟进清单.csv | 派生 | 由回访明细.csv 筛选低分客户生成 |
| 满意度分区分析.md | 派生 | 由回访明细.csv 与投诉记录.md 汇总 |
| 评分分布统计.csv | 派生 | 由回访明细.csv 汇总 |
| 问卷题目.md | 参考 | 本轮问卷 |

处理口径：

| 字段 | 处理方式 |
|---|---|
| 客户姓名 | 替换为“客户A/B/C…”序号 |
| 手机号 | 整列删除 |
| 客户编号 | 保留 |
| 评分 / 分类 / 结论 | 保留 |

**派生文件与原始文件同等处理**：上表标为“派生”的文件是从原始数据加工出来的，凡是把姓名或联系方式带进去的，一样按口径处理；不要因为它们是“加工过的结果”、不是原始回收数据就跳过。
