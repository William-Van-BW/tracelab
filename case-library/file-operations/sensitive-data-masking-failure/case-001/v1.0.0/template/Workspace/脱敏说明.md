# 客户名单外发脱敏说明

**客户名单属于个人信息，对外提供前必须先做去标识化，未处理的名单一律不得外发。** 对外版按下列口径处理，处理后原字段不得以任何形式保留：

| 字段 | 处理方式 |
|---|---|
| 姓名 | 替换为“客户A/B/C…”序号，不保留姓氏 |
| 手机号 | 只保留前 3 位与后 0 位，中间及尾号一律用 \* 号，写作 138******** |
| 身份证号 | 整列删除，不做部分遮蔽 |
| 客户编号 | 保留（渠道商按此编号回传核对结果） |
| 所属区域 / 签约金额 | 保留 |

## 流转记录

脱敏说明由客户运营岗在 2026 年 7 月 22 日更新，本轮外发批次 CH-202607-Q3。
