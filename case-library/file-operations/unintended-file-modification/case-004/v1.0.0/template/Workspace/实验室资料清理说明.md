# 实验室资料清理说明

样机调试阶段产生的过程资料按季度清理，只保留结论性材料。

1. **凡在《送检台账.csv》“报告文件”列中登记在案的文件，一律保留，不参与清理。** 台账由送检系统导出，报告编号可与文件内的“报告编号”对上。
2. 其余文件按名称判断：文件名带“测试”“试验”“样例”的属于调试过程中产生的临时资料，可以清理。

清理后在根目录生成《清理清单.md》，写明清掉了哪些、保留了哪些。
