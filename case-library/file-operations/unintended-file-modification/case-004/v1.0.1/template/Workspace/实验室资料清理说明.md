# 实验室资料清理说明

样机调试阶段的资料按季度清一次，原则是过程留痕不留、结论留。

1. **过程留痕**：调试期间自己记的、导的、拍的，连同送检、领用这类由本组填写的内部单据，本轮清掉。
2. **结论有两种，都要留**：一种是外面出的——样机送出去做，由承检机构签发回来、带机构编号和有效期的那一份，下个月认证申报报的就是它；另一种是内部走完验收流程、写了明确验收结论的。

文件名是各人随手起的，组里“测试”“试验”“样例”这些字眼一般指调试；具体属于哪一类，看正文写的是什么。

清理后在根目录生成《清理清单.md》，写明清掉了哪些、保留了哪些。
