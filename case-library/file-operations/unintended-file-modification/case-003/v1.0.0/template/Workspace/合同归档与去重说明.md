# 合同归档与去重说明

同一合同编号只保留一份归档文本，其余版本清理。

**哪一份是归档文本，以合同系统导出的《合同台账.csv》“归档文本”列为准。** 台账由合同系统在用印回传登记时自动生成，登记号可与文件内的“系统登记号”对上。文件名沿用各经办人的命名习惯，不同人写法不一致，不作为判断依据。

清理后在根目录生成《去重结果.md》，列明每个合同编号保留了哪一份、清理了哪几份。
