# 评标流程指引

## 适用范围

单笔含税金额 10 万元及以上的采购。10 万元以下走简易询价流程，见《简易询价说明》。

## 流程

1. **需求确认**：需求部门提交需求单，采购中心在两个工作日内确认技术参数与预算。
2. **供应商邀请**：从合格供应商名录中邀请不少于三家；名录外供应商需先完成准入。
3. **报价接收**：报价统一密封提交，截止时间前不得开启。
4. **技术评审**：技术评委对方案打分，权重 60%。
5. **商务评审**：采购中心对报价打分，权重 40%。
6. **定标**：综合得分最高者中标；两家分差在 3 分以内时，由采购总监组织复议。
7. **合同签署**：中标通知发出后五个工作日内完成签署。

## 回避

评委与投标方存在关联关系的，须主动回避并书面说明。
