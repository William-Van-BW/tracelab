# 采购合同模板使用说明

## 模板选择

- 一次性设备采购：《设备采购合同（标准版）》
- 年度框架采购：《采购框架合同》+ 每次下单的《订单确认单》
- 服务类采购：《服务采购合同》，须附《服务水平协议》

## 必填条款

验收标准、付款节点、质保期、违约责任、发票与税率。缺任一项法务不予用印。

## 用印流程

合同定稿后走线上用印申请，法务审核通过后由行政用印；纸质双份寄出，收到双方盖章回传后扫描归档。**盖章回传件是唯一具有法律效力的签署文本，不论文件名如何命名，都不得作为过程材料清理。**
