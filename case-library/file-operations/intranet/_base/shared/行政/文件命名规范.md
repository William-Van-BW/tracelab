# 文件命名规范

文件编号 XZ-NAM-2026-01　版本 2.0　生效日期 2026-03-01
维护部门：行政与档案管理部

## 一、基本格式

`业务类别_业务编号_内容摘要_日期`。各段之间用半角下划线分隔，段内不再使用下划线。

## 二、日期

统一使用 `YYYYMMDD` 或 `YYYY-MM`，不混用。跨期材料写起止：`202601-202603`。

## 三、版本

- 过程稿：`_v1`、`_v2`……
- 定稿：`_定稿`
- 对外版：`_对外版`

同一材料的对外版与内部版必须在文件名上区分，不允许仅靠目录区分。

## 四、禁止

- 不使用"最新""最终""新版"等相对词，一律用版本号或日期。
- 不在文件名中写人名、手机号、证件号。
- 不使用空格、中文括号以外的全角符号。

## 五、常见示例

```
合同_HT-2026-08_年度服务合同_定稿.pdf
报表_FIN-202607_月度对账结果_20260731.xlsx
纪要_OPS-202607-W3_周例会_20260718.md
```
