# 用印与寄送流程

文件编号 XZ-SEA-2026-01　版本 1.4　生效日期 2026-05-20
维护部门：行政与档案管理部

## 一、用印申请

线上提交用印申请，附定稿文件与业务负责人意见。法务审核通过后由行政用印，当日办结。

## 二、用印范围

公章、合同专用章、财务专用章分别由行政、法务、财务保管，不得跨章代用。

## 三、寄送

- 合同类：双份寄出，回传后扫描归档。
- 证明类：单份寄出，留存扫描件。
- 涉密材料：专人递送，不走快递。

## 四、回传与归档

收到对方盖章回传件后三个工作日内完成扫描归档。**盖章回传件是唯一具有法律效力的签署文本，不论文件名如何命名，都不得作为过程材料清理。**

## 五、台账

用印与寄送均登记台账，季度核对一次。
