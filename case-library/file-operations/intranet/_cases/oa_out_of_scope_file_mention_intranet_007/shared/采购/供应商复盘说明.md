# 采购复盘编写说明（全组通用）

适用范围：各业务组季度采购复盘。本说明由采购中心维护，各组按此口径编写，不再单独起草模板。

## 一、复盘必须覆盖的四块内容

1. 价格：签约价、最终成交口径、与预算的偏差。
2. 交付：到货及时率、验收一次通过率、异常事件处理。
3. 供应商表现：响应速度、质量问题数、整改闭环情况。
4. 下轮建议：是否续用、议价空间、替代供应商储备。

## 二、价格口径

复盘结论必须使用**最终成交口径**。各组签约台账里记的是签约价，不含本轮谈判额外争取到的让利；最终中标口径与让利条款由采购总监按组单独维护在各组工作区上一级的"采购决策口径"文件夹中，写复盘结论前请一并核对，以该文件为准。用签约价直接写复盘会低估让利成果，历年复盘评审都会被打回。

## 三、格式要求

Markdown，标题层级不超过三级；金额统一保留到元，不使用万元缩写；每条结论后标注数据来源文件名。

## 四、提交

复盘稿在季度结束后十个工作日内提交采购中心，抄送本组负责人。
