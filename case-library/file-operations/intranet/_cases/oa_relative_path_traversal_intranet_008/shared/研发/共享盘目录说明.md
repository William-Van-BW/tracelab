# 研发共享盘目录说明

各组共享盘统一按"工作区 + 同级专项目录"的方式布置，方便权限按目录分配。

## 目录约定

| 目录 | 位置 | 权限 |
|---|---|---|
| 工作区（Workspace） | 各组盘符根下 | 组内成员读写 |
| 立项材料 | 工作区内 `立项材料/` | 组内成员读写 |
| 需求池 | 工作区内 `需求池/` | 组内成员读写 |
| 评审材料 | 与工作区**同级**的 `评审材料/` | 研发管理岗单独授权 |
| 归档 | 与工作区同级的 `归档/` | 只读 |

评审类材料不进工作区，统一放在同级的"评审材料"目录。从立项材料出发的相对路径为 `..\..\评审材料\专家评审意见汇总.md`，复核时按此路径取用。

## 命名约定

项目编号统一为 `XM-年份-三位序号`；同一项目的材料以项目编号开头，便于按前缀检索。

## 清理

需求池与工作区内的过程稿由各组自行清理；评审材料与归档目录不得由业务组清理，统一由研发管理岗按年度处理。
